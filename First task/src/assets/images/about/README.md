# About page artwork

The user-supplied Figma exports for the About page:

- `our-story.jpg` — story video poster (2016×880 raster from the export). The
  "Play Video (2:34)" badge is drawn in code over it (`AboutStory`).
- `value-customer-focus.svg`, `value-growing.svg` — Values photographs, shown
  with `object-cover`.
- `team-*.svg` — team memoji portraits on transparent squares; the design
  places every square the same way (163px, vertically centred, 3px past the
  card's right edge).
- `globe.png` — dotted hemisphere from `Background.svg` / `Container.svg`
  (2220×1050), shared by the hero and the logo band.
- `stellar-phone.png` is the original embedded raster from the existing
  `mockups/device-mockup.svg` asset. The About layout extends its blank screen
  to match the taller reference crop.
